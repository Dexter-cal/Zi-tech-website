hi# Zitech Limited - Enterprise IT Solutions Platform

Welcome to the modular, full-stack website and management platform for Zitech Limited.

## Features
- **Modular Frontend**: Decoupled HTML, CSS, JavaScript modules.
- **RESTful Express Backend**: Full Node.js API supporting dynamic content fetching, contact form submissions, consultation bookings, and newsletter subscriptions.
- **Admin Management Panel**: Secure administrative portal with credentials management, content CRUD, inquiry viewing, and configuration settings.
- **Security**: JWT authentication, bcrypt password hashing, default admin account (admin / admin12), and password change capability.
- **Convenient Launch Scripts**: Instant start using start.sh (Linux/macOS) or start.bat (Windows).

## Quick Start
Run the platform using:
./start.sh
or on Windows:
start.bat

Access the application in your browser at http://localhost:3000.
